# Automation Demo

**Python | Playwright | Web Automation**

---

## About

Demonstrative project showing web automation with Python and Playwright. This is a clean, independent version inspired by internal automation work — no proprietary data, credentials, or company information included.

---

## What It Does

- Automates repetitive web tasks
- Fills forms and extracts data
- Takes screenshots for documentation
- Handles errors gracefully

---

## Tech Stack

`Python` `Playwright` `Async/Await` `Error Handling`

---

## How to Run

```bash
pip install -r requirements.txt
playwright install
python main.py
```
